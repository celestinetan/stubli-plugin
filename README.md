# Stubli

A kinder social network for everyone, on your own WordPress site. Share photos, follow friends, comment. No ads, no algorithm, no central server.

**Stubli is in beta.** Anyone is welcome to try it and tell us what works and what doesn't.

Stubli turns a WordPress site into a calm, familiar place for photos and the people you like. Sites talk to each other directly with RSS and Webmention.

- **Get started:** https://stubli.app/welcome/
- **Try it in your browser** (temporary, nothing is saved): [WordPress Playground](https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/celestinetan/stubli-plugin/main/blueprint.json)
- **Feedback:** https://stubli.app/feedback/

## Install

1. Use a host that lets you upload plugins (on WordPress.com, any paid plan).
2. Download [stubli.zip](https://github.com/celestinetan/stubli-plugin/releases/latest/download/stubli.zip), then in WordPress: Plugins → Add New Plugin → Upload Plugin.
3. Stubli's setup opens by itself. When you finish, it adds the free Webmention plugin that carries comments between sites.

See `readme.txt` for details, including which outside services Stubli talks to and when.
